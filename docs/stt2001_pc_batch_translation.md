## 批量機制

- `pc/p1/export_batch.py` 唯讀匯出 `pc/p1/data/dialogues.bin`（STTB0002），保存 UID、原始字碼、繁中譯文及來源前 16 bytes。來源相同但譯文不同時拒絕匯入，避免選錯語境。
- 原始字串必須只有普通字、`FFFB` 換行及 `FFFD/FFFE` 結尾；繁中不含變數／標籤，來源與譯文行數相同，最多四行。短於 8 bytes 的來源拒絕匯入。
- 原版文字處理器 `0x8004BA68–0x8004BAD4` 分派結尾碼；`0x8004BCD0`／`0x8004BCE0` 設定狀態 4／5，經 `0x8004BCEC–0x8004BCF8` 前進指標。新增 FFFE 時沿用原版狀態，沒有改變流程。
- 以八個來源 bytes 建立索引；目前段落先走快速檢查，必要時從文字指標向後最多 2,048 bytes 尋找完整特徵。還需匹配原始前文 16 bytes，避免僅憑常見字串片段替換。
- 繁中沿用既有逐行進度比例映射，維持原版更新、輸入和週期。不是獨立計時的中文字顯示引擎。
- 不縮小字型來硬塞長句。以實際 Microsoft JhengHei 28 raster pixels 測量行寬，超出原文字起點至右界 304 的範圍時保留日文。未新增自動分頁。
- `0x8004A7D8` 仍只隱藏劇情繪字來源 `RA=0x8004BDB0`，新增以 `$s5 & 255` 限定已匹配槽位。該暫存器源於 `0x8004B934` 的函式參數。其他槽位、姓名和一般文字入口繼續原版繪製。
- X 的同步仍限定已驗證的旁白呼叫位置；其他場景的隱藏分支尚待分別確認，不能聲稱全遊戲通用。
