# STT2001 繁體中文化：PC 反編譯版優先路線

日期：2026-11-06。使用者已選定 **Windows PC 版優先**。本文件依本機《機戰F反編譯_純淨版_1103》成品的靜態檢查、既有 STT 資料，以及 [PSXRecomp 官方專案](https://github.com/RetroPortingToolKit/psxrecomp) 與[遊戲專案建置指南](https://github.com/RetroPortingToolKit/psxrecomp/blob/master/docs/GAME_PROJECT_SETUP.md)規劃。沒有執行該成品或修改遊戲映像。

## 《機戰F》成品實際包含什麼

| 證據 | 可確認的結論 | 尚不能推定 |
|---|---|---|
| `完结篇/SRWF_Recompiled.exe` 是 x64 Windows PE；`game.toml` 指向 `SLPS-01924`、原版光碟與 PS1 載入位址。 | 這是原遊戲程式轉成 PC 執行環境的成品，玩家仍提供日版光碟資料。 | STT 的 PS-X EXE 可不經適配直接套用。 |
| `完结篇/zh_ff.bin` 以 `SRWX` 開頭，大小約 3.8 MB；EXE 包含 `SRWF_PACK`、`zh_ff.bin` 及「pack … glyphs, … entries」診斷字串。 | 有獨立漢化資料包，應同時儲存文字與字形／索引；確切欄位格式未反解。 | `SRWX` 後各整數的語義或 STT 可直接讀取此包。 |
| `完结篇/fonts/font.ttf` 約 9.7 MB；EXE 內有 `SRWF_FONT`、字型路徑、`cmap/loca/glyf` 等字串。說明文件稱 F8 可切換「系統字體／原版點陣」。 | PC 端有獨立字型繪製路徑，能避開 PS1 單張 VRAM TIM 字庫容量。 | 所有文字一定都走同一個字型鉤子。 |
| EXE 包含 `srwf_xlate_push/page/interp/draw/getstr`、`srwf_glyph_probe`、`font banks`、`vram patch`、`hits/miss` 等診斷字串。 | 成品有多個文字攔截與字模相關處理點；同時保留某些 VRAM 字形修補路徑。 | 字串本身不能證明每個函式的呼叫順序、覆蓋率或快取演算法。 |
| EXE 匯入 Win32 GDI 與 OpenGL 函式，包內有 OpenBIOS。 | Windows 原生繪製與 PS1 硬體運行層並存；不需要修改 Sony BIOS。 | 它能產出可在 PS1 實機或一般模擬器執行的漢化 ISO。 |

包內只有執行檔、資料、字型、設定與原版光碟副本，**沒有可供 STT 直接改寫的《機戰F》漢化原始碼**。`(1)` 同名副本與兩份說明文件顯示包曾被重複整理；本次不把檔名日期當作可重現版本號。PSXRecomp 官方說明其原理是將 PS1 MIPS 程式轉為 C，再與 PS1 硬體運行層編譯成原生應用；遊戲專案需要自己的設定、函式種子、光碟識別與生成碼，並非把另一遊戲 EXE 換檔名即可使用。

## STT2001 應借用的部分

1. **重編譯原版遊戲程式，保留原版光碟為只讀資源。** 以 `ROM/Super Tokusatsu Taisen 2001 (Japan).cue` 建立獨立 STT 專案；先證明原版標題、選角、第一關能啟動並保存狀態，再接漢化。
2. **把 `334.xlsx` 當成唯一譯文來源。** 現有 UID／出現位置、41,352 個引用、角色名對應、排版檢查和場景資料能用作翻譯包生成輸入；需把文字 ID 對上 PC 運行時的實際讀取／繪製點。既有 SwanStation sidecar 與 v8–v10 的地址、字碼映射只能作研究線索，不能直接當成新 runtime 已通過驗證。
3. **先做 PC 字型替代，再考慮遊戲字庫兼容層。** PC 的 TTF／OTF 可承載全量繁體字，不受 EVENT #20 原尺寸 344 安全字位或 tpage30 的限制。仍需攔截遊戲文字流程，處理控制碼、對話節奏、文字寬度、名字、選單、戰鬥字串及原版日文回退。
4. **翻譯包與執行程式分離。** 先做版本化、可檢查的 `UID → 原文引用 → 繁中譯文` 資料，執行期只讀載入。這是借用《機戰F》成品的架構思路，並不採用其未解明的 `SRWX` 二進位格式。

## 最小里程碑與驗收

| 里程碑 | 交付／驗收 | 主要阻礙 |
|---|---|---|
| P0 原版啟動 | STT 專案能以原版 CUE 在 Windows 啟動至選角並進入第一關；原版畫面、輸入、存讀檔有基準記錄。 | 本機目前未見 `psxrecomp` 原始碼或 CMake／Ninja／C++ 編譯工具鏈；《機戰F》成品不含 STT 建置源碼。 |
| P1 單句接入 | 以 `334.xlsx` 的 UID 對應第一關一段對話，在 PC 字型模式顯示正確繁中；日文回退、換行、逐字顯示、頁面清除正常。 | 需找 STT 在重編譯運行時的文字查表／提交繪製點，不能直接借《機戰F》地址。 |
| P2 覆蓋三類文字 | 劇情、選單／姓名、戰鬥台詞各取一組；確認不必重繪整張 PS1 TIM。 | 三類文字可能有不同呼叫鏈；原 PS1 UI 佈局會限制長句。 |
| P3 全量導入 | 匯出 21,423 譯文單位，逐類檢查 41,352 個出現位置，處理動態插值與缺字。 | 資料完整性、版面及全流程 QA，而非單純字庫容量。 |

**第一個具體實驗**只做 P0：從 STT 原版 CUE 產生自己的 `game.toml` 與函式種子，重編譯／執行原版到第一關；原版無法穩定啟動時，不加入翻譯鉤子。這遵循官方建置指南的「每個遊戲獨立專案」流程。P0 過關後才用最小一段對話實作 P1。

## 結論與邊界

2026-11-06 進度更新：P0 工程已成功建置；使用者已確認標題、選角、第一關、輸入及存讀檔通過，P0 驗收完成。下一步進入 P1 單段繁中接入；詳見 [P0 驗證報告](stt2001_pc_p0_build_validation.md)。音訊及完整遊戲流程未因此視為通過。

《機戰F》的可借鑑方法是 **PC 靜態重編譯 + 原版光碟只讀掛載 + 獨立翻譯包 + PC 字型顯示**。這能讓 STT 的全量繁體字不再受單一 PS1 VRAM 字庫限制，但會形成 Windows PC 版，**不是**單一 PS1 漢化 ISO；實機相容性不在此路線的驗收範圍。當前已證實的是參考成品的組件與可見介面；其內部掛鉤位置、`SRWX` 格式、STT 重編譯啟動可行性都尚未驗證。無需先完成 EVENT #20 A/B 安全邊界追蹤。
