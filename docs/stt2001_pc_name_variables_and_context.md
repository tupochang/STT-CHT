# PC 姓名變數與敗北條件漏譯修正

2026-11-07。回報的三張畫面分別為 U00161、U00103、U00246。當次日誌載入 15,725 筆資料，具有新版逐頁診斷，因此不能歸因於使用者未啟動新版。

## 定位與更正

- U00161 含 `[HERO2]`，即使變數只在後頁，舊匯出器仍排除整段，所以第一頁「偵測到腦波異常」也沒有繁中。
- U00103 正文含兩次 `[HERO2]`，同樣被排除。不能以固定的「タクマ」代替，因為玩家可改名。
- 真正的「味方が全滅させられたとき」為 U00246（STAGE0005 +0x5A8A 等）。原始字碼在全遊戲有四種譯文；目標前文 16／32 bytes 仍有三種，64 bytes 有兩種，128 bytes 才能區分該位置。
- **更正上一份報告：U00244 是另一項勝利條件「擊倒蜘蛛男及所有修卡戰鬥員」，不是敗北條件。** 先前合成 RAM 測試只驗證雙槽機制，選錯敗北測試資料，未證明實際敗北文字會被納入。本次改用 U00243／U00246 測試。

## 共用修正

### HERO1–HERO4

靜態 MIPS 指向同一配置指標 `*(0x800BD350)`：

| 控制碼 | 配置內姓名偏移 | 最多字碼 | 設定文字指標的程式 |
| --- | --- | ---: | --- |
| FF01 | +0x24E | 8 | 0x8004BAEC–0x8004BB0C |
| FF02 | +0x272 | 5 | 0x8004BB10–0x8004BB30 |
| FF03 | +0x260 | 8 | 0x8004BB34–0x8004BB54 |
| FF04 | +0x27E | 5 | 0x8004BB58–0x8004BB78 |

原處理器把腳本指標暫存在槽位 `+0x24`，將 `+0x20` 改指向姓名緩衝區，並在末尾寫 FF05。`0x8004BB7C–0x8004BB84` 恢復腳本指標，再前進至後續正文。

新增 `caption_names.h`：

- 匯出時允許 `[HERO1]` 至 `[HERO4]`，逐頁核對對應 FF01–FF04 次數；其他變數／控制碼維持拒絕。
- 原生字層從配置的實際姓名字碼解析文字，使用現有 kana table／固定字型 11 對照表；不改寫 RAM 姓名，不硬編碼玩家名字。
- 姓名顯示期間，以已儲存的原腳本指標維持原段落匹配，並加入姓名內的出字進度；回到正文時繼續原頁。
- 把姓名展開為原頁的來源進度和繁中字串，再以實際字寬排版。姓名改變時重新排版；原版姓名標題仍保留。
- 只讀已確認的 8／5 字碼欄位；原版首次使用前尚未寫入 FF05 也不越界。輸出去掉尾端填充空白，但來源進度保留填充字碼數。配置或字碼對照不可用時拒絕該頁，記錄 `reason=name_unavailable`，不顯示 `[HERO2]` 或猜測姓名。現有字碼對照不代表所有自訂漢字姓名皆已畫面驗收。

### 來源衝突

來源前文由 16 改為 128 bytes。相同原字碼但不同譯文依前文各自保留；只有同一原字碼與同一完整前文仍對應不同譯文時才拒絕。匹配必須同時通過原字串及其前文，沒有依最先遇到的譯文任選。

這是共用選擇規則，其他場景遇到相同短句而譯文不同時也適用。仍無法辨識的來源不強行翻譯。合成 RAM 保留完整 128-byte 前文，避免測試只匹配字串本身。

## 結果與限制

| 匯出資格 | 修正前 | 修正後 |
| --- | ---: | ---: |
| 譯文單元 | 15,281 | 15,973 |
| 劇情位置 | 17,586 | 18,561 |
| 特徵紀錄 | 15,725 | 16,409 |
| STAGE0005 位置 | 176 | 201 |

仍排除未支援變數／標籤位置 6,922、過短來源 778。這些是離線資格數，不是實際畫面驗收數。

合成 RAM 檢查通過：

1. 實際 U00103 展開「タクマ」，姓名緩衝區指標往返期間仍保持原句，姓名出字進度繼續增加。
2. 把姓名改為「サキ」後會重排，不保留舊名字。
3. U00161 第一頁可顯示「腦波」，不因後頁含姓名變數而整段回退。
4. 真實 U00243／U00246 來源與前文可在兩槽同時匹配，分別清除；U00246 已列入匯出資格。
5. 16,409 筆逐頁進度檢查、既有翻頁、重排、返回、關閉及原框渲染回歸通過。

上述未執行劇情，不宣稱三張實際畫面已修正通過。金手指效果仍未測試。中文詞組的斷行品質是另一項排版工作，本次沒有宣稱已解決「簡／稱」等語意分行問題。

## 使用

新 EXE：`pc/build-runtime/STT2001_PC_Chinese_Names.exe`；新資料 `pc-data-v5/`（STTB0005、128-byte 前文），另有 `name-glyphs.bin`。舊 Paged EXE 及 `pc-data-v4/` 保留。

關閉舊遊戲後執行原命令：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\STT\pc\launch-p1.ps1"
```

本次優先驗收三張回報對應的 U00161、U00103、敗北條件；其他尚未支援的文字入口與變數仍可能顯示日文。
